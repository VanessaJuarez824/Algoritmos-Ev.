# Evidencia1-TC2038.607
Aplicación Web para el procesamiento de archivos de texto plano.

Funcionalidades:
BUSCAR. Buscar un patrón P en un texto T. Se deben encontrar todas las apariciones del patrón y resaltarlas con color amarillo sobre el texto original. Para realizar esta operación debe hacer uso ya sea del algoritmo KMP o Z. La búsqueda puede incluir letras, palabras, o enunciados (esto incluye los espacios en blanco entre palabras).
SIMILITUD. Encontrar la subcadena común más larga entre dos textos T1 y T2 . Es decir, se encontrará la similitud más grande entre los textos. La subcadena encontrada se deberá resaltar en color azul. Para esto, implemente el algoritmo LCS.
PALÍNDROMO. Buscar el palíndromo más grande en un texto T. Resaltar el palíndromo con color verde. Usar el algoritmo Manacher para realizar esta operación.
AUTO-COMPLETAR. Conforme el usuario escriba texto en un text field se deberá mostrar una lista desplegable de opciones para auto-completar el texto. Para esto, parta el contenido del texto original en palabras para así generar tokens por palabra. Mantenga los tokens mediante la estructura de datos Tries.
